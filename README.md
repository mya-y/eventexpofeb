# Milad Expo & Lomba Pelajar 2026 — FEB UMS Rappang
Website pendaftaran lomba dan expo untuk siswa SMA/SMK se-Kabupaten Sidenreng Rappang (HTML/CSS/JS + Google Apps Script).

- `index.html`: halaman publik dan formulir pendaftaran.
- `admin.html`: panel panitia (login, data pendaftar, konfirmasi, unduh CSV, buka/tutup pendaftaran).
- `js/config.js`: semua isi acara dan URL Web App Apps Script.
- `apps-script/Code.gs`: kode server yang ditempel di Google Apps Script (petunjuk pasang ada di dalam file).

Mode demo aktif jika `appsScriptUrl` di `js/config.js` diawali "GANTI": data tersimpan di browser.
